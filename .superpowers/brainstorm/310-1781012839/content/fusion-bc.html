设计要素总结

层面方案
背景深空渐变 (#06060f → #0c0c20 → #120d30) + 紫蓝径向光晕 + 细微网格纹理
卡片玻璃拟态: rgba 半透明 + backdrop-filter: blur(20px) + 细边框 rgba(255,255,255,0.06~0.08)
布局Bento Grid: CSS Grid 不对称网格，Hero 跨2行，置顶跨2列，分类入口跨2列
强调色靛蓝 #818cf8 为主 + 紫色 #a78bfa 为辅，用于渐变标题、标签、发光边框
标签每种主题独立色系（蓝/紫/青/绿/橙/粉），毛玻璃药丸标签
置顶文章紫蓝渐变发光边框 + 右上角渐变 PINNED 角标
分类卡片4 等分内嵌网格，每个有独立 emoji + 计数
文字层级纯白标题 / 40% 透明度正文 / 20% 透明度元数据
响应式桌面 3 列 Bento → 平板 2 列 → 手机单列垂直堆叠
