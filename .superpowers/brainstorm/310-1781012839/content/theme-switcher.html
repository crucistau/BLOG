项目方案
实现方式CSS 变量 (Custom Properties) — 三套变量值，切换时改 <html data-theme="...">
状态持久化localStorage 存储用户选择，刷新保持；默认跟随系统 prefers-color-scheme
切换 UI导航栏右侧小图标按钮，点击弹出下拉/循环切换三种
代码组织每个主题 ≈ 30 行 CSS 变量定义，三套独立文件或集中管理
Markdown 渲染代码块高亮主题也跟随切换 — Amber 用 Monokai、Dracula 用 Dracula、Slate 用 GitHub Light
